# ani-dl
Утилита для скачивания и просмотра аниме с Kodik.

# Возможности
- Поиск по названию
- Одновременное скачивание нескольких эпизодов
- Возможность небольшой автоматизации: указание Shikimori ID, ID перевода, 
эпизодов
